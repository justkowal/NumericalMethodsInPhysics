\section{Matrix Rows Accessor}

The rows accessor retrieves row dimensions efficiently. Here we demonstrate referring to the snippet by its \textbf{real location only} with line numbers disabled:

\codesnippet[
    ref = location,
    linenos = false,
    label = snip:rows
]{src/Matrix.cpp}{Matrix::rows}

\section{Scoped Environment Example}

You can also scope a specific root to an environment block:

\begin{codesnippetproject}[ref=both, refformat=bracket]{..}
The BLAS-accelerated multiplication kernel inside a scoped environment (bracket reference format):

\codesnippet[
    label = snip:blas
]{src/Matrix.cpp}{Matrix::multiply_blas}
\end{codesnippetproject}

\section{Cross-Referencing Snippets in Document Prose}

Snippets can be referenced in body text by their semantic name, real location, or line range:
\begin{itemize}
    \item Constructor: \snippetref{snip:ctor} is defined in \snippetloc{snip:ctor} (lines \snippetlines{snip:ctor} of \snippetfile{snip:ctor}).
    \item Accessor: \snippetref{snip:rows} is located at \snippetloc{snip:rows}.
    \item BLAS Kernel: \snippetref{snip:blas} is located at \snippetloc{snip:blas}.
\end{itemize}
